# lazizjonov.uz
Lazizjonov Personal OS — personal website

## Website source

The complete buildless website lives in `dist/index.html`: HTML, CSS, JavaScript, and Uzbek, Russian, and English content. No package installation or build step is required. Open `dist/index.html` in a browser to preview it. Google Fonts requires an internet connection; fallback fonts remain available offline.

The site includes language switching, About, Projects, Research, Journey and Contact windows, career/education tabs, GitHub projects, the expandable Oila hamkori case, contact links and a Tashkent clock.

Current hosted site: https://lazizjonov-personal-os.jammycity.chatgpt.site/

## Editing

Edit `dist/index.html` and keep UZ/RU/EN content consistent. Check language switching, modal opening/closing, project and journey tabs, case expansion and contact links in a browser. Preserve the distinction between design-stage work and verified implementation results.

## Source hosting versus deployment

This repository stores source code and version history. Updating GitHub does not automatically update the existing Sites deployment. GitHub Pages or another host requires separate configuration to serve `dist/`. No deployment workflow or custom-domain configuration is included here.
